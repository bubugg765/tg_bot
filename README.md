# tg_bot
Телеграм бот для администрирования игрового проекта
Бот предназначен для управлением лицензиями, пользователями и контроля доступа.

**Основной функционал:**
- Генерация и удаление лицензионных ключей.
- Блокировка и разблокировка по IP, HWID, никнейму или ключу.
- Проверка блокировок и просмотр информации о лицензии.
- Сброс HWID и хэша загрузчика.
- Заморозка и разморозка ключей.
- Управление версиями и статусом технических работ.
- Загрузка и обновление файлов через Telegram.
- Разграничение команд для администратора и обычных пользователей.
